# Bao & Sul invitation redirect

This repository preserves previously shared invitation links at https://sulbao4eva.github.io/bao-sul-wedding/ and redirects guests to https://sulbao4eva.github.io/invite/. The invitation source and full history are in `sulbao4eva/invite`.

GitHub Pages publishes `main / (root)`. The redirect works with JavaScript, with an HTML refresh and visible link as fallbacks.
